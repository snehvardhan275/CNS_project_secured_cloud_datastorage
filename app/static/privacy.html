ACADEMIC PROTOTYPE

Privacy and security notice

This site is a student project prototype. It is not a production cloud-storage service or a formal security product.

What this version does

This version supports account registration and email verification. File upload, cloud file storage, and file encryption are not enabled yet.

Information used for accounts

The prototype stores your username, email address, an Argon2id password hash, and account creation time. It sends verification and sign-in codes by email. The server stores a keyed hash of each code rather than the code itself. Session records expire after eight hours; verification codes expire after five minutes.

Use a unique password

Do not reuse a password from another site. This prototype has not undergone an independent security audit. Do not enter financial, medical, or other highly sensitive information.

Project source and contact

The source code and project history are available in the project repository. Report security concerns through its Issues page.
